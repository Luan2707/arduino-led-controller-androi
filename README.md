📱 Arduino LED Controller (Android App)

Aplicación móvil desarrollada para Android orientada al control y gestión de hardware, permitiendo encender, apagar e interactuar con iluminación LED mediante una placa Arduino y comunicación inalámbrica/Bluetooth.

### 🚀 Funcionalidades
- **Control en tiempo real:** Envío de señales y comandos directos a la placa Arduino.
- **Interfaz intuitiva:** Control de estados y acciones rápidas para la gestión de iluminación.
- **Módulo de acceso:** Estructura para inicio de sesión y gestión de estados de la aplicación.

### 🛠️ Stack Tecnológico
- **Plataforma:** Android Nativo (Kotlin)
- **Construcción y dependencias:** Gradle Kotlin DSL (`build.gradle.kts`)
- **Hardware integrado:** Arduino UNO / Nano con módulo de comunicación (Bluetooth / Serial)
